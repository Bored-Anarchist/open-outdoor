# Deep dive: rights language for 111 agency source roles

**Checked:** 2026-09-27 UTC. **Scope:** the 111 non-New-York source roles marked Unconfirmed before this pass in the [rights matrix](STATE_AGENCY_REDISTRIBUTION_RIGHTS_2026-09-26.md). These are role records, so repeated URLs are reviewed once but listed for each agency role. This is a source-terms audit for copying, filtering/modifying, combining, and publishing a derivative as machine-readable public Git and downloadable offline data, including downstream redistribution. It does not decide geographic completeness, visitor access, or live conditions.

## Method and outcome

- Re-read all 111 rows and queried the public `info/iteminfo?f=pjson` endpoint for **77 distinct ArcGIS services** covering 97 roles. Every query succeeded on 2026-09-27. Of those services, 45 had an empty `licenseInfo` field (60 roles), one literally said `None` (two roles), and 31 contained text (35 roles). The text is credit, limited app use, public-use/planning language, or a disclaimer; none clearly grants the planned public modified bulk/offline redistribution.
- Reviewed the linked pages for the other 14 roles (12 distinct URLs), plus applicable publisher language. The clearest new finding is the [Michigan DNR website policy](https://www.michigan.gov/dnr/about/DNR-Website-and-application-policies): it requires prior written permission for copying, modifying, publishing, and derivatives unless law otherwise provides. The two Michigan roles move from Unconfirmed to **Permission required** for the current DNR webpage source. A future exact portal dataset with its own license needs a separate decision.
- The resulting 142-role matrix is **17 Supported, 6 Conditional, 109 Unconfirmed, 3 Permission required, 1 Restricted, and 6 Lead only**. No newly reviewed data were acquired or added to a public package. The 109 still-Unconfirmed roles lack an affirmative source-specific grant; this is not a finding that each publisher forbids reuse.

A warranty disclaimer, source credit, a download button, a public-access label, and a statement allowing noncommercial app use answer different questions from public derivative redistribution. The table below records the rights-language gap for each source. When an ArcGIS service has child layers, the service item terms are the evidence checked; verify any child/item-specific terms before acquisition.

## Required publisher language

For each remaining source, the publisher's grant should identify the exact item or a policy expressly covering it and permit: (1) downloading/copying the selected records, (2) filtering and modifying geometry and attributes, (3) combining with other data, (4) publishing the modified extract in a public Git repository and downloadable offline app packages, and (5) recipient copying and redistribution. It should specify attribution, change notices, commercial/noncommercial limits, share-alike obligations, third-party lineage, and whether refreshed extracts are covered. The [earlier request template](STATE_AGENCY_RIGHTS_AND_LEADS_RECHECK_2026-09-26.md#recheck-of-the-original-93-rights-entries) remains suitable when adapted to the exact URL. No agency was contacted in this audit.
