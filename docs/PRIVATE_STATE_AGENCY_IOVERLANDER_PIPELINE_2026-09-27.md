# Private state agency + iOverlander pipeline

**Status:** private validation is active for the 107 pinned Unconfirmed agency roles. This pipeline writes source data and combined state overlays only under the Git-ignored `PrivateData/` root. The publisher-rights matrix remains Unconfirmed for these roles; public packages and downstream redistribution require a separate grant and release review.

As of September 27, 2026, the local private ledger records 101 of 107 Unconfirmed roles represented by selected, staged data: 71 original exact roles, 16 selected service roots, six roles sharing staged service URLs, and [eight resolved alternate sources](AGENCY_PENDING_SOURCE_RESOLUTION_2026-09-27.md). The six remaining roles have no exact acquired visitor layer; KS and NE appear to be forestry registry scope errors, LA and NC have official visitor references without verified vector extracts, and two Maryland DNR services remain unavailable. Of five Permission required roles, three NJDEP roles are staged for local validation under the [NJDEP GIS FAQ](https://dep.nj.gov/gis/faq/); the project owner approved private Michigan staging but confirmed no DNR copying grant, so two Michigan roles remain uncollected under the [DNR terms](https://www.michigan.gov/dnr/about/DNR-Website-and-application-policies). One selected Florida park boundary child returned HTTP 500, while four other children from that service staged successfully. Active private packages now cover all 50 states: 43 agency+iOverlander packages, the separate New York DEC+iOverlander package, and six iOverlander-only packages for CA, CT, MA, MI, MN, and NE. The 49-state builder contains 432,068 agency features and 62,147 iOverlander places; including New York, the verified totals are 446,522 agency/DEC features and 63,333 iOverlander places. See the [50-state package inventory](PRIVATE_STATE_PACKAGE_INVENTORY_2026-09-27.md). The Florida, Georgia, and Texas ZIPs and Oklahoma KML have derived private GeoJSON with verified raw checksums and role-specific selection. New York also packages 5,289 verified DEC elevation profiles; see the [integration report](PRIVATE_PACKAGE_INTEGRATION_2026-09-27.md).

## Inputs and output

- The [provisional source list](../config/agency-provisional-private-validation-2026-09-27.json) pins the exact 107 agency role IDs. The [connector](../tools/state-agency-feeds.mjs) uses source-specific local approvals and stores raw features with checksum receipts at `PrivateData/agency-feeds/US/<code>/<source-id>/`. The source URL, rights status, private-only setting, and retrieved time are recorded in each receipt.
- `PrivateData/sources/ioverlander/US/<state>/tiles_<version>/` supplies the existing per-state iOverlander archive. The builder checks base-tile MD5s against its source manifest, removes contributor IDs, deduplicates place GUIDs, and filters points against the [U.S. Census Bureau's 2026 state boundary service](https://tigerweb.geo.census.gov/arcgis/rest/services/TIGERweb/State_County/MapServer/0). Census boundaries are cached in `PrivateData/reference/`.
- `node tools/build-private-state-agency-ioverlander.mjs <code>` combines verified staged agency GeoJSON and iOverlander places at `PrivateData/catalogs/US/<state>/current/agency-ioverlander.private.geojson`, alongside a checksum manifest. When no eligible agency records are available, it builds an `ioverlander-only` package with zero agency features. `--all` builds all 49 states outside New York and writes a private build report. California uses both tile packages; GUID deduplication spans packages and shared exports are clipped separately to each state. Duplicate agency URLs assigned to multiple roles are loaded once unless a verified partition selects distinct features. Florida, Georgia, and Texas ZIPs are parsed by `convert-private-agency-shapefiles.py`; Oklahoma KML is parsed by `convert-private-agency-kml.py`. The Florida converter selects 76 named forest polygons from the March 2025 layer and transforms EPSG:3087 to WGS84. Oklahoma selects 44 historical state-park location points, excluding seven federal entries and one canoe-trail entry; current management and access are unverified.
- `node tools/report-private-state-packages.mjs` verifies the active GeoJSON checksums and counts for all 50 states plus the New York profile checksums, map binding, and trail geometry, updates the ignored private inventory and build report, and writes the public counts-only [package inventory](PRIVATE_STATE_PACKAGE_INVENTORY_2026-09-27.md). It excludes historical archives and does not publish private places or narratives.
- Agency features in the combined overlay carry `reviewStatus: provisional`, `rightsStatus: Unconfirmed`, and a private-use caution. They are not certified visitor POIs or current access guidance. The combined overlay is a private validation input, not a public package or an automatic mobile bundle.
- The [reviewed child-layer selections](../config/agency-provisional-child-selections-2026-09-27.json) identify visitor-related layers within service roots. `stage-provisional-agency-children.mjs` creates exact local approvals and stages those layers. A service root alone is never treated as a data layer.
- The [alternate-source selections](../config/agency-pending-source-resolutions-2026-09-27.json) and [Permission required role decisions](../config/agency-permission-required-private-validation-2026-09-27.json) drive `stage-private-agency-resolutions.mjs`. NJDEP records retain `rightsStatus: Permission required` and `publicDistribution: false`; the Michigan roles have no acquisition approval.
- The GA converter keeps 60 DNR-owned state-park polygons and seven Forestry Commission owned polygons, transforming their UTM coordinates to WGS84. The TX converter keeps 113 park boundaries marked open for public use and transforms the Texas projected coordinates. Both outputs and their raw ZIPs stay in `PrivateData/` with checksum provenance. These boundaries still require current access review. The NJ overlay selects 9,265 public-access Parks and Forestry parcels with visitor-use labels, 62 accessible state trails, 54 public open-space points, and 762 state-managed POIs without explicit closed or restricted status. Raw NJDEP data stay private and untouched; the filters apply during the combined build.

## Repeatable commands

```text
node tools/state-agency-feeds.mjs init-provisional
node tools/stage-provisional-agency-feeds.mjs --max-features 10000
node tools/stage-provisional-agency-feeds.mjs --max-features 200000
node tools/stage-provisional-agency-children.mjs --max-features 200000
node tools/stage-private-agency-resolutions.mjs --max-features 200000
python -m pip install --target PrivateData/vendor -r tools/agency-shapefile-requirements.txt
python tools/convert-private-agency-shapefiles.py
python tools/convert-private-agency-kml.py
node tools/build-private-state-agency-ioverlander.mjs --all
node tools/package-private-new-york-hikes.mjs
node tools/stage-private-mobile-map.mjs --input "PrivateData/catalogs/US/New York/current"
node tools/report-private-state-packages.mjs
node tools/report-provisional-agency-status.mjs
```

The batch staging command skips sources with receipts already present, records failures in `PrivateData/agency-feeds/batch-report.json`, and enforces the source-advertised ArcGIS page size up to 1,000 features. Service roots need exact child-layer selection; download or information pages need direct files or adapters. The commands do not add agency or iOverlander records to Git.
