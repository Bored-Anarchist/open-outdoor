# State parks, forestry, and OpenStreetMap dataset audit

**Reviewed:** 2026-09-26. **Scope:** the 50 state agency rows in `config/us-state-forestry-agencies.json`, the 49 built state packages, the New York outdoor package, and OSM-derived map inputs. This is an inventory and source-selection audit, not a new acquisition or a certification of permission, current access, or redistribution rights.

## Agency source audit across all 50 states

The [agency source audit](STATE_AGENCY_SOURCE_AUDIT.md) and [visitor-use audit](STATE_AGENCY_OUTDOOR_USE_AUDIT.md) enumerate the 98 non-New-York agency rows and their supplemental sources; the [New York audit](NYS_AGENCY_SOURCE_COVERAGE_AUDIT.md) covers the other two. The registry currently classifies the 49 non-New-York **parks** primary candidates as 34 APIs, 9 downloads, 5 catalogs and 1 information page. **Forestry** has 21 APIs, 11 downloads, 13 catalogs and 4 information pages. These are discovery classes, not integration or suitability grades. A portal is not a dataset, a canopy raster is not a managed-forest boundary, and a trail point is not a route.

Do not infer state forest, open trail or camping rights from vegetation or state ownership. |

**Selection rule for every state:** retain PAD-US as a traceable national baseline; prefer an exact agency or state-stewarded polygon for park/forest units, a separately managed line dataset for trails, and a point dataset for developed camping/visitor amenities. Use several datasets per agency where needed. Match IDs and manager fields, de-duplicate by geometry/name/manager, preserve each source's rights and update date, and do not turn a spatial join into an agency endorsement. Temporary closures, fire restrictions, road status and permits require their own timestamped authoritative feeds. No direct state candidate is approved for public bundle release by this audit.

## OpenStreetMap audit and recommendation

OSM is valuable for base cartography and can reveal paths, campgrounds, parking, toilets and other mapped services. Its tags and contributor coverage vary by place. A `tourism=camp_site` feature or path crossing public land is not evidence of designated camping, public access, seasonal availability or current safety. Geofabrik supplies current state PBF extracts and reports file/source timestamps on its download pages; use a **dated, checksum-pinned** extract for repeatable builds rather than a mutable `latest` URL. The public extracts omit contributor usernames, IDs and changeset IDs. [Geofabrik US download page](https://download.geofabrik.de/north-america/us.html).

Use the existing Protomaps PMTiles for map context. If detailed OSM outdoor features are added, import them as a separate, visibly community-sourced layer and preserve OSM element type/id, tags, extract date, source URL, geometry and attribution. Filter out `access=private/no`, `disused`, `abandoned`, `proposed`, construction and other nonvisitor features as appropriate; still present access as unknown unless an authoritative manager confirms it. Compare against agency routes/sites, but preserve separate provenance and avoid silently merging license regimes. Publish OSM-derived database outputs only after the [ODbL attribution and share-alike](https://www.openstreetmap.org/copyright) review required by the project scope; keep an accessible OSM credit and license link in offline and online map views. The [Protomaps terms](https://docs.protomaps.com/basemaps/downloads) describe its archive as an ODbL produced work with OSM attribution.
