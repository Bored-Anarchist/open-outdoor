# Phase 1 Recorder Alpha Gate

**Status:** Implemented; physical acceptance pending

The Windows-verifiable Phase 1 core covers the application shell and adapters, private activity/user-trail schema, sequenced recorder state, distance/elevation revisions, activity-library workflow, GPX/GeoJSON privacy transforms, authenticated encrypted staging restore, and fixture-backed offline map.

The gate remains blocked because browser/Windows evidence cannot substitute for the current reference iPhone. Before Phase 1 is accepted, run the recorder through screen lock, suspension, process termination, permission loss, weak GPS, pause/resume, and explicit finish; repeat the 30-minute memory smoke with the Phase 1 UI; complete VoiceOver, largest Dynamic Type, bold text, contrast, reduced motion, and 44-point target review; and capture a controlled physical barometric climb within the binding threshold.

The diagnostics-only guided runner persists across process termination, walks the tester through permission recovery, combines screen-lock, radio/GPS, memory, and controlled-climb evidence into one field run, detects the required accessibility configuration, and exports one coordinate-free report. Follow [the guided acceptance procedure](PHASE_1_GUIDED_ACCEPTANCE.md); repository ingestion independently re-evaluates thresholds and prepares an evidence proposal without bypassing reviewer sign-off.

Measured battery draw and thermal endurance remain explicitly deferred to WP-307/WP-503. No Phase 1 battery-life claim is made.
