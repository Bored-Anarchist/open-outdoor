# Idaho, Arkansas, and South Dakota agency dataset deep dive

**Checked:** 2026-09-26. **Purpose:** select land, trail, camping, and visitor-location inputs for the offline public project. Counts below are live ArcGIS `returnCountOnly` results on this date, not proof of complete or current coverage. None of these newly identified agency records has been copied into a public package.

The [project scope](../PROJECT_SCOPE.md) allows publicly redistributed source data only when its independent terms cover storage and redistribution. Noncommercial operation satisfies a noncommercial condition but does not supply a missing redistribution grant. An empty ArcGIS `licenseInfo` is **unknown**, not open licensing.

## Release decision and next verification

1. **Usable now under existing recorded rights:** the already bundled federal/PAD-US layers and the separately licensed OpenStreetMap extracts remain independent context. OSM additions need attribution and ODbL share-alike handling; they cannot imply legal access or current closures.
2. **New agency inputs identified, not yet redistributable in this repository:** the exact layers in the table. Public service availability, download buttons, and noncommercial operation do not resolve the missing offline/public redistribution terms. No agency geometry was added to public assets in this audit.
3. **Highest-value requests:** ask IDPR for a current 30-park boundary export and explicit offline bundle rights; ask IDL about State Ownership/Public Recreation republication; ask Arkansas State Parks/GIS Office about polygon, trail, and `ASP`/`AFC` facility subsets; ask GFP for park/trail offline redistribution and a current facilities feed; ask DANR whether it manages any visitor-access forest property and has a public layer.

Query method: ArcGIS layer metadata (`?f=pjson`), count queries (`/query?where=1%3D1&returnCountOnly=true&f=json`), and filtered owner/class queries were checked live on 2026-09-26. Feature counts are snapshots and may change. No copyrighted map tiles, photos, or source geometries are reproduced here.
