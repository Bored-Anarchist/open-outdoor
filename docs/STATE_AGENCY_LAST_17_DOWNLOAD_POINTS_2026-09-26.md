# Last 17 state agency source leads: download-point audit

**Checked:** 2026-09-26 EDT / 2026-09-27 UTC. **Purpose:** find direct data endpoints behind the 17 Lead only roles left by the [first pass](STATE_AGENCY_RIGHTS_AND_LEADS_RECHECK_2026-09-26.md). Searches covered agency pages, ArcGIS service catalogs and item metadata, and live layer schemas. Queries for field names and small samples did not copy agency feature data into Git. A direct endpoint is a technical source-selection decision; the [rights matrix](STATE_AGENCY_REDISTRIBUTION_RIGHTS_2026-09-26.md) still controls public modified-derivative distribution.

**Result after the remaining-ten follow-up:** nine of these 17 roles now point to direct queryable layers in the [registry](../config/us-state-forestry-agencies.json) and [complete dataset tracker](ALL_DATASETS_TRACKER.md). Colorado and Texas were resolved in a second pass; eight remain leads because the closest public data are inaccessible, belong to a different manager, describe fire/forest planning rather than visitor land, or have no verified public vector endpoint. No agency records were imported. The 142-role rights matrix now contains 109 Unconfirmed and eight Lead only records.
