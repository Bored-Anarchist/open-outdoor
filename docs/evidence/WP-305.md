# WP-305 evidence

**Status:** Composed public/private/user experience implemented; local acceptance passed on 2026-09-02

Composed queries now retain an explicit public-catalog, private-catalog, or private-user origin, the source catalog identity/version, and redistribution rights. Version-keyed private overlays can hide, relate, or correct reference display without mutating the read-only catalog. User trails are sourced only from the writable private snapshot and remain present when the private reference catalog is removed.

The default composed export includes only redistributable public records. Private-catalog material requires an explicit include decision and compatible rights; private-user trails require explicit per-record selection. Catalog remaps and accepted promotion links update associations on a cloned snapshot while leaving user trail content unchanged.

`T-E2E-003-C01` covers composition and origin labels, `C02` covers private-extension removal, `C03` covers publication isolation, and `C04` covers non-destructive remap/promotion behavior.

Verification: strict TypeScript build and `packages/storage/test/composition.test.ts`.
