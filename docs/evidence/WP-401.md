# WP-401 evidence

**Status:** Implemented; automated acceptance passed on 2026-09-09.

`pnpm source create <connector-id>` generates a runnable synthetic connector with its manifest, typed model, parser/normalizer, fixture, contract test, attribution, and health definition. It uses the accepted WP-206–WP-208 SDK conventions and requires no core registration changes. Unsafe IDs and existing destinations fail without overwriting connector work. The generated manifest permits only the included local synthetic fixture.

`packages/data/test/source-scaffold.test.ts` generates all artifacts in an isolated directory and launches the generated full connector contract in a separate Vitest process. The test verifies validated emission and durable raw/checkpoint behavior, malformed input rejection, and overwrite/traversal rejection.

See [Connector ecosystem](../CONNECTOR_ECOSYSTEM.md) for usage and source-authorization requirements. Real-source activation and canonical mappings remain the responsibility of each new connector, as with the existing SDK.
