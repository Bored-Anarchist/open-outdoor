# WP-304 evidence

**Status:** Offline explore/search/details index implemented; local acceptance passed on 2026-09-01

Generated public catalogs include a deterministic local FTS5 index alongside their R-tree bounds. The runtime reference index loads only public/private read-only catalog records and exposes explicit no-network text search, segment/polygon-aware spatial search, bounds, and facet filters for lands, trails, and places. Filters cover source, ownership, category, camping status, freshness, record type, and distance. Result ordering is deterministic and the capability contract explicitly excludes live verification, turn-by-turn guidance, and rerouting.

Details retain bundle version/origin/coverage, source identity and attribution, field provenance, source freshness, active bundled restrictions, camping evidence, local media availability, and explicit live/rights-excluded content gaps. Private user records are rejected from the reference index.

`T-E2E-001-C01` covers local text/spatial/facet search and the navigation boundary. `C02` covers provenance, stale state, restrictions, camping evidence, bundle origin, and unavailable offline media.

Verification: strict TypeScript build and the WP-304 Vitest suite.
