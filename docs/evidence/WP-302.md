# WP-302 evidence

**Status:** Production pack builder implemented; local acceptance passed on 2026-09-01

The production builder applies explicit region, high-detail-area, entity, media, and distribution selection to immutable catalog components. Selected inputs fail closed when offline storage, derivation, redistribution, license, attribution, terms-review, expiry, checksum, or SBOM metadata is incomplete. Requested region/entity/media coverage must be present after filtering.

Every successful build emits a deterministic manifest, SBOM, DBOM, inclusion/exclusion report, and exact size rows keyed by region, source, entity class, media class, zoom, distribution, artifact, and component. It enforces the 1.5 GiB basemap, 1 GiB catalog/search/elevation, 512 MiB media, and 3 GiB combined installed ceilings.

`T-REL-002-C11` covers selection and reports. `C12` covers incomplete rights and coverage. `C13` covers binding component and combined size failures.

Verification: strict TypeScript build and the WP-302 Vitest suite.
