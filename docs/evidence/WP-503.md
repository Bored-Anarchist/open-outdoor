# WP-503 evidence

**Status:** Implementation and automated verification complete. Physical performance/endurance runs are deferred to Phase 5 end by owner-approved ADR-049; no battery-life or native-performance claim is made.

The recorder now serializes mutations and avoids empty snapshot writes. Regression tests prove zero additional writes for 720 empty refreshes, persistence retry before acknowledgement, acknowledgement retry without duplicate writes, refresh/pause serialization and recovery lifecycle persistence. The UI refresh loop is foreground-only, allows one operation at a time and cancels future timers when hidden/disposed. Unchanged checkpoints skip metric/map recalculation; display points are bounded at 2,048 without changing durable observations or algorithms.

The desktop profiler produces repeat distributions and raw samples for the synthetic page/search/map schematic/scroll and a 100,000-point display input. It successfully executes and is explicitly supplemental, not a New York scale/native GPU/battery result. The strict production evaluator validates the unchanged iPhone 14/iOS 26.6 budgets, missing/invalid samples, candidate identity, independent run intervals, repeated evidence, thermal/battery/storage/sensor limits and reviewer attestation. Simulator/browser substitution, reused runs, charged runs and invalid telemetry fail closed.

Validation: 329 tests in 49 files through `pnpm quality`, privacy/boundary checks, the combined `pnpm phase5:quality` runner, five Python tests, governance validation and an iOS Hermes export (596 modules). `phase5:quality --verify-physical` remains blocked without device evidence, as intended by ADR-049. Reports and the unexecuted template are generated in `dist/production-quality`.

The native layer still writes full snapshots for nonempty batches, and updated metrics still process accumulated observations. The final long-track/max-catalog profiles must establish whether more optimization is needed. Three independent ≥180-minute runs per Balanced/Endurance mode and all physical accessibility/performance tests remain mandatory before WP-506 acceptance.
