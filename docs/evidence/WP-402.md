# WP-402 evidence

**Status:** Accepted on 2026-09-09 by Bored-Anarchist. See the [Phase 4 acceptance disposition](../PHASE_4_GATE_REPORT.md).

The shared AcquisitionSession and REST, bulk, ArcGIS, WFS, RSS/Atom, local-file, and display-only overlay adapters apply manifest rights, HTTPS host/redirect checks, content and streaming byte limits, per-run budgets, cancellation, timeouts, bounded transient/network retries, and single-request concurrency. Bulk inventory inspection rejects traversal, links, device names, alternate streams, excessive depth/size/expansion, and compression bombs before format-specific decoding.

The acquisition suite proves redirects/pagination cannot leave allowed hosts, disabled or expired sources never contact the transport, failed staging never advances checkpoints, interrupted pagination resumes at the saved next locator, and ETag/checksum checkpoints are bound to their source/version/URL. GIS completeness checks reject short pages inconsistent with advertised totals. Private local input is copied only after explicit user selection; overlays remain non-queryable.

The sink owns atomic staging and durable checkpoint persistence; replay must be idempotent. Format-specific archive/native decoders and service-specific parsing are separate SDK components. See [Connector ecosystem](../CONNECTOR_ECOSYSTEM.md).
