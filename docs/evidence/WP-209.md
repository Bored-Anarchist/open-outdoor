# WP-209 evidence

**Status:** Implemented prototype; local acceptance suite passed on 2026-08-31

The public-pack builder emits a deterministic SQLite catalog with strict metadata, source inventory, canonical records, R-tree bounds, approved external artifacts, coverage, exclusions, and a DBOM. Its external manifest binds the bundle/content/schema versions, New York bounds, compatible app interval, offline capabilities, classification, attribution, rights snapshot, freshness, sizes, and SHA-256 checksums.

Requested sources fail the build when authorization, review lifetime, derivation, offline storage, public distribution, license, disclaimer, or attribution is incomplete. Records remain separately excluded when unregistered, non-public, invalid, tombstoned, outside the approved type set, or missing required attribution. Artifact URLs must use HTTPS on the source allowlist and carry a SHA-256 checksum. Existing outputs are never overwritten and an oversized catalog is removed before a manifest can be published.

`T-REL-002-C01` proves byte-identical catalogs and manifests from the same inputs and audits the SQLite contents. `T-REL-002-C02` proves revoked rights and the catalog byte ceiling fail closed.

Verification: strict TypeScript build and the WP-209 Vitest suite.
