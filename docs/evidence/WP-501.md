# WP-501 evidence

**Status:** Implemented with automated validation on 2026-09-09. Physical production acceptance remains separate; no device or performance acceptance is claimed.

WP-501 adds the original Open Outdoor token/icon system, reusable native controls/cards/notices/metrics/details, a semantic browser catalog with all 24 field states, and three local map style documents. The [product design system](../PRODUCT_DESIGN_SYSTEM.md) records the XL decomposition, low-fidelity flow baseline, component-state matrix, asset provenance, renderer contract and reproduction steps.

## Automated evidence

- `pnpm quality`: types, formatting, release/native/workflow validation and 305 tests across 45 files pass. The native validator now checks shared component target tokens and scalable text rather than the removed inline button styles.
- `pnpm test:privacy`: 10 privacy tests and public boundary scan pass.
- `pnpm test:design:browser`: seven groups cover 320/1024 widths, light/dark/high contrast, 200% text, minimum targets, all field states, keyboard skip/focus, search/filter/empty/detail, native capability, private origin, state transitions, disabled/busy controls, reduced motion and zero external requests. Six synthetic screenshots plus a JSON report are generated in `dist/design-qa`.
- `pnpm build:ios:bundle`: Expo exports the iOS Hermes bundle successfully (593 modules). This is a JavaScript bundle check, not a signed device or Xcode build.
- `scripts/Test-Wp001.ps1`: governance and relative-link validation pass.
- Python regression suite: five tests pass using the existing virtual environment.

`T-E2E-001-D01` and `D02` provide 12 targeted tests for contrast, exhaustive state/icon coverage, optional feedback policy, safe HTML details, map hierarchy, clustering, local-only assets and canonical input preservation. `D03` is the durable browser runner and is integrated into the design CI job for relevant changes. A 320-pixel/200%-text heading overflow found during testing was fixed before publication.

## Rights, privacy and remaining gates

All new visual geometry and design assets are project-authored with AI assistance under Apache-2.0. Examples are synthetic; no personal/source-restricted content, third-party visual assets, runtime network requests, storage migrations or new sensor work is introduced. Playwright is a pinned development dependency.

The mobile shell still uses its existing fixture map adapter; style documents are supplied for a production renderer without claiming native GPU-render evidence. Physical iPhone 14 VoiceOver, Dynamic Type, Bold Text, Increase Contrast, outdoor readability and haptic acceptance remain WP-502; performance/energy/endurance remain WP-503; final production acceptance remains WP-506. The component catalog and browser evidence cannot waive those gates.

Hosted Windows CI exposed the first CSS asset missing an explicit LF attribute. The fix adds `*.css text eol=lf` and was verified by checking out the stylesheet with `core.autocrlf=true` and rerunning formatting.
