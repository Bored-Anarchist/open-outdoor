# WP-403 evidence

**Status:** Implemented; automated acceptance passed on 2026-09-09.

The import-export package accepts lawful user-selected GPX, GeoJSON, KML, CSV, and position-bearing FIT files. It preserves GPX segment boundaries, point/route geometry, applicable names/timestamps, provider/file/format/parser provenance, and private classification. Atomic private staging includes the source SHA-256; invalid batches never call the destination. Public destinations are rejected.

Synthetic tests cover all formats, CSV quoting and explicit account-export column mappings, AllTrails/iOverlander provenance, XML entities/nesting/network links, invalid UTF-8 and coordinates, payload/aggregate-point limits, and FIT endianness/developer fields/compressed timestamps/CRC corruption. Account mapping tests assert no network requests. No private service records or schemas were added.

This is shared import/staging API acceptance, not native file-picker/device acceptance. Unsupported archive and geometry types are documented and fail explicitly. See [Connector ecosystem](../CONNECTOR_ECOSYSTEM.md).
