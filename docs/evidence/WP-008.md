# WP-008 evidence — private/reference database, backup, and compatibility spike

**Status:** Implementation complete; physical iPhone acceptance pending

Accepted ADR-017 and ADR-018 for the Phase 0 spike. The autolinked Swift storage coordinator uses native SQLite3, opens the private user database with read/write/create plus WAL, and opens catalog databases with `SQLITE_OPEN_READONLY`. Catalog paths resolve symlinks and must remain below the declared public/private catalog roots. The active spool, sealed user database, WAL/SHM, and catalogs receive their declared iOS protection and backup-exclusion attributes.

The platform-neutral storage contract provides:

- explicit query/write capabilities with no writable catalog or writable-attach capability;
- current-plus-previous app/catalog/backup compatibility preflight before mutation;
- the exact combined-catalog free-space formula, including the 9 GiB maximum-profile result;
- checksum, compatibility, free-space, and remap fail-closed behavior; and
- an interruption matrix that retains the old catalog before pointer switch, rolls back after an unconfirmed switch, and never changes private record digests.

Windows-verifiable cases pass for T-INT-001-C01–C02, T-INT-002-C01–C08, and T-INT-006-C01–C06.

Still required on the iPhone 14 running iOS 26.2:

- inspect protection and `isExcludedFromBackupKey` on the main database, WAL, SHM, spool, catalogs, and replacements;
- prove locked-screen spool access and sealed-library denial;
- inspect an iOS system backup for absence of private/regenerable content;
- execute the full same-identity A→B refresh/upgrade with activities, notes, favorites, attachments, associations, remaps, promotions, and an unresolved link;
- run incompatible app/catalog/backup downgrade attempts and prove failure before mutation; and
- force pointer/first-launch failures on device and verify user record counts/hashes remain unchanged.

Explicit encrypted backup cryptography and full reinstall/restore remain WP-107/WP-306; this spike establishes protection, exclusion, separation, and compatibility boundaries only.
