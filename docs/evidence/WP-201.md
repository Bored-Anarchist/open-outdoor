# WP-201 evidence

**Status:** Implemented; local acceptance suite passed on 2026-08-30

The `@open-outdoor/data` package now exposes a versioned connector SDK and a committed JSON Schema for source manifests. Lifecycle, authorization, acquisition mode, source class, classification, distribution, retention, attribution, endpoint, secret-name, freshness, and resource-limit fields are independently required and validated. Rights evaluation fails closed for inactive, unauthorized, expired, mismatched-mode, unretained, unapproved-field, non-derivable, offline-prohibited, and distribution-prohibited requests.

The synthetic connector contract exercises `discover`, `fetch`, `store_raw`, `parse`, `normalize`, `validate`, `checkpoint`, and `emit` in order. This verifies `REQ-DAT-001`, `REQ-SRC-001`, and `REQ-SRC-002` at the framework boundary; production connectors remain later work.

Verification: strict TypeScript build and `packages/data` Vitest suites, including JSON Schema validation through Ajv.
