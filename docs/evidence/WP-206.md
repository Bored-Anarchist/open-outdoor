# WP-206 evidence

**Status:** Implemented connector foundation; local acceptance suite passed on 2026-08-31

The active New York land registry targets the NYS ITS civil boundary, USGS PAD-US, NYS DEC lands, and USDA Forest Service surface ownership. These are production connector definitions classified `SOURCE_REDISTRIBUTABLE`; they are not replaced with synthetic source records. ArcGIS discovery requests the complete object-ID set and emits deterministic pages. PAD-US requires a caller-supplied pinned release locator.

Normalization preserves source identity, partition, timestamps, field provenance, ownership, manager, geometry quality, attribution, and disclaimer. Private ownership remains an inholding signal rather than public-land eligibility. Partition pins include payload and geometry SHA-256 checksums, and the completeness gate rejects gaps, duplicates, count mismatches, or incomplete pages.

`T-INT-003-C01` through `C04` cover rights activation, land/inholding normalization, pagination, stable partitions, checksums, complete geometry, and freshness reporting.
