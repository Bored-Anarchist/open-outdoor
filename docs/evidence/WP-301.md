# WP-301 evidence

**Status:** Deterministic basemap build contract implemented; local acceptance passed on 2026-09-01

The New York basemap builder consumes an authorized HTTPS OSM extract only after its SHA-256 matches the pinned source record. It rejects the OpenStreetMap public tile service as an acquisition source and requires complete provider, timestamp, boundary, license, redistribution, and attribution metadata. The extract boundary must contain the declared New York release bounds.

The builder verifies the pinned compiler executable bytes, invokes that compiler through the build adapter using a defensive copy of the verified extract, and records the generated MBTiles archive checksum. It records schema/style versions and layer coverage, requires statewide detail through zoom 14, and validates configured zoom 15–16 outdoor areas. Style documents, sprites, and fonts must be local; every asset carries license and attribution metadata. The 1.5 GiB basemap ceiling fails closed.

`T-REL-002-C10` proves deterministic manifests and rejects tile-server acquisition, checksum drift, remote style resources, and incomplete rights.

This package establishes the production build and reproducibility gate without committing a third-party New York extract or generated tile archive. A release build must supply the reviewed dated extract pin and compiler artifact externally.

Verification: strict TypeScript build and the WP-301 Vitest suite.
